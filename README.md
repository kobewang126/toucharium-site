# Toucharium website

Static product, support, privacy and source pages for Toucharium. The site is
published from the repository root with GitHub Pages; `.nojekyll` preserves
plain static files. It has no runtime dependencies, analytics or remote fonts.
Chinese and English content is included in the HTML. The language control uses
the `lang` URL parameter without storing a browser preference.

Preview with `python3 -m http.server 8080`.

Website code and the original Toucharium mark are GPL-2.0-or-later. The guest
screenshot depicts Ubuntu Touch and retains its respective third-party rights.
The application source is linked from the site's open-source page.
