# Toucharium website

Static product, support, privacy and source pages for Toucharium. The site is
published from the repository root with GitHub Pages; `.nojekyll` preserves
plain static files. It has no runtime dependencies, analytics or remote fonts.
Chinese and English content is included in the HTML. The language control uses
the `lang` URL parameter without storing a browser preference.

Preview with `python3 -m http.server 8080`.

Website code and the original Toucharium mark are GPL-2.0-or-later. The guest
screenshots depict Ubuntu Touch and retain their respective third-party rights.
The home page shows phone and desktop-window simulator captures; the support
page owns the usage guide for the V2.0 external-image version.
The image preparation page owns the download, Linux setup, packaging and import
instructions, with copyable commands and an optional Mac VM workflow.
The application source is linked from the site's open-source page.

Versioned release pages own the shipped component inventories, extracted notices,
image adaptation source and corresponding-source availability status. These
materials distinguish verified provenance from outstanding source and permission
work; inventories alone are not complete corresponding source.
