CREDITS & LICENCES

尊重开源，也尊重原作者。Open source, with credit where it’s due.

项目来源Project origins

Toucharium 基于 imxieyi/Kernarium，复用其 Linux 运行时、虚拟设备及宿主显示输入能力。客体用户空间来自 UBports Ubuntu Touch PDK。感谢这些项目及其贡献者。Toucharium is based on imxieyi/Kernarium, reusing its Linux runtime, virtual devices, and host display and input. The guest userspace comes from the UBports Ubuntu Touch PDK. Thank you to these projects and their contributors.

公开的修改Published changes

源码包括独立的 Toucharium App、运行时扩展、Linux 内核配置与补丁、持久化支持，以及镜像派生、触控、显示缩放和输入法策略生成工具。The source includes the Toucharium application, runtime extensions, Linux kernel configuration and patches, persistent storage support, and image, touch, display-scaling and keyboard policy producers.

系统镜像与对应源码System images and corresponding source

V2.0 不内置系统镜像，用户自行准备并导入兼容镜像；仓库提供离线打包、镜像策略和适配工具。App 中的运行时、内核与启动配置仍适用各自许可证。旧版内置镜像的版本 1.0（10）来源、组件、许可证和源码获取状态保留备查；其完整第三方对应源码材料仍在整理，镜像派生脚本不等同于全部系统源码。V2.0 does not bundle a system image. Users prepare and import compatible images; the repository provides offline packaging, image policies and adaptation tools. Runtime, kernel and boot configuration components retain their own licences. The older bundled image’s version 1.0 (10) provenance, components, notices and source status remain available. Complete third-party corresponding-source materials for that release are still being assembled; image producers are not the source of the entire system.
