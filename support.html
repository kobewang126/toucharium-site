V2 / DEVELOPMENT GUIDE

从第一次导入，到你的日常用法。From your first import to everyday use.

以下是 V2 外置镜像开发版的使用说明，包含 iPhone 与 iPad。App Store 下载仍在等待官方答复，开发版功能不代表已发布版本。This guide describes the V2 external-image development build on iPhone and iPad. App Store downloads remain on hold awaiting a reply; development features do not imply a released build.

在哪里下载？Where can I download it?+

App Store 下载入口仍暂停，等待 Ubuntu 官方答复后，再考虑上架安排。可以先观看产品介绍视频或查看开源构建说明。本网站不提供 IPA 或系统镜像下载。The App Store download link remains on hold awaiting a response from Ubuntu’s representatives. You can watch the product video or read the open-source build guide. This website does not distribute an IPA or system image.

镜像从哪里来？需要什么文件？Where do system images come from?+

V2 开发版不内置系统镜像。按照镜像准备工具的说明取得基础镜像，在 ARM64 或 x86-64 Linux 中离线打包；Mac 可使用 Linux 虚拟机。导入需要一份 .erofs 镜像和工具生成的配套 .erofs.import.json。校验用于确认完整性，不代表镜像来源或官方认可。本网站不分发系统镜像。The V2 development build does not bundle a system image. Follow the image preparation guide to obtain a base image and package it offline on ARM64 or x86-64 Linux. A Mac can use a Linux VM. Import the resulting .erofs image and its matching .erofs.import.json. Verification checks integrity, not provenance or endorsement. This website does not distribute system images.

第一次如何导入镜像？How do I import an image for the first time?+

用 AirDrop 等方式把镜像和配套 JSON 传到设备，在“文件”App 中存到同一个文件夹。打开 Toucharium，点 Import system image，在文件选择器中同时选择这两个文件。必要时先打开“选择”模式。导入期间保持 App 在前台，等待复制和完整校验结束；只有校验成功才会选用新镜像。Transfer the image and its matching JSON to your device, for example with AirDrop, and save both in the same folder in Files. Open Toucharium and tap Import system image. Select both files together; enable Select mode in the picker if needed. Keep the app in the foreground while copying and full verification finish. A new image is selected only after verification succeeds.

导入后，外部原文件还能删除吗？Can I delete the original files after importing?+

可以，但请先确认导入成功并能正常启动。导入会把完整镜像复制到 App 的 Documents 中，不会一直依赖“文件”App 中的外部原文件。之后可以删除外部原镜像和配套 JSON，避免多占一份空间；不要删除 Toucharium 应用目录中的已安装镜像或数据文件。导入过程需要同时容纳原文件、App 内副本以及可写数据，请提前留足空间。Yes, after you confirm the import succeeded and the system starts normally. Import copies the entire image into the app’s Documents directory; it does not keep using the external original. You can then delete the external image and JSON to save space. Do not delete the installed image or data files inside Toucharium’s app directory. Allow enough storage for the original, the imported copy and writable guest data during import.

每次启动都要重新导入吗？Do I need to import on every launch?+

不用。一次成功导入后，后续启动和覆盖更新 App 会继续使用已安装的镜像。卸载 App、手动删除或修改已安装镜像，可能需要重新导入；卸载也会删除 App 内的系统数据。No. After a successful import, later launches and in-place app updates reuse the installed image. Uninstalling the app or deleting or modifying its installed image may require another import. Uninstalling also removes the app’s guest data.

如何更换系统镜像？How do I replace the system image?+

点齿轮进入 Emulator Settings → Storage → Change system image…，确认停止当前系统，再选择新镜像和配套 JSON。取消或校验失败会保留旧镜像。更换完成后，从 App 切换器彻底关闭 Toucharium，再重新打开；仅切到后台不算重新启动。Tap the gear and open Emulator Settings → Storage → Change system image…. Confirm stopping the current system, then select the new image and its matching JSON. Cancelling or a failed verification keeps the previous image. After the change, close Toucharium from the app switcher and reopen it. Merely putting it in the background is not a relaunch.

更换镜像时，数据如何处理？What happens to data when I replace an image?+

Keep existing data 是默认选项，沿用已有文件、账号和设置，请选择兼容镜像。Start fresh 使用全新数据环境：确认后，只有新镜像校验并切换成功才删除旧数据，不保留历史备份。取消导入或校验失败不会删除旧数据。最终仅保留当前的一份用户数据；重要文件请事先备份。Keep existing data is the default. It reuses your files, accounts and settings, so choose a compatible image. Start fresh uses a new data environment: after confirmation, old data is deleted only once the new image is verified and selected. No historical backup is retained. Cancelling or a failed verification leaves old data intact. Only the current user data is retained; back up important files first.

手机界面和桌面窗口模式怎样切换？How do I switch between phone and desktop windows?+

在 Emulator Settings → Ubuntu Touch interface → Interface mode 选择 Phone mode 或 Desktop windows，点 Save 后彻底关闭并重新打开 App。iPhone 首次默认手机模式，iPad 首次默认桌面窗口模式，之后保留你的选择。桌面模式的应用有标题栏及窗口按钮，可打开多个窗口，拖动标题栏调整位置。In Emulator Settings → Ubuntu Touch interface → Interface mode, choose Phone mode or Desktop windows. Tap Save, then close and reopen the app. iPhone initially defaults to phone mode and iPad to desktop windows; later selections are preserved. Desktop apps have title bars and window controls. Open several windows and drag their title bars to arrange them.

有哪些手势和横竖屏技巧？Which gestures and orientation tips are useful?+

从客体画面的左边缘滑入可呼出启动器，点应用抽屉图标浏览应用；从客体顶部向下滑动可打开系统指示器。请从 Toucharium 内部的系统画面开始手势。iPhone 横屏时，宿主控制按钮移到右侧，并为顶部手势留出空白；iPad 和 iPhone 竖屏时按钮在底部。Swipe inward from the guest display’s left edge to reveal its launcher and tap the app drawer icon to browse applications. Swipe down from the guest’s top edge for system indicators. Start gestures inside the guest display. On landscape iPhone, host controls move to the right and space above the guest separates top-edge gestures. On iPad and portrait iPhone, controls stay at the bottom.

如何选择系统键盘或 iPhone 键盘？How do I choose the guest or iPhone keyboard?+

在 Emulator Settings 的 Hardware 下方找到 Keyboard，选择输入法并保存，然后彻底关闭并重新打开 App。默认使用客体系统内置键盘：点输入框会由客体系统处理键盘的显示和隐藏。选择 iPhone 键盘时，先点客体应用的输入框，再点宿主控制栏的键盘按钮；点客体画面可收起 iPhone 键盘。当前宿主按键映射主要支持英文、数字与常见符号。In Emulator Settings, find Keyboard below Hardware, choose an input method and save, then close and reopen the app. The guest keyboard is the default; the guest handles its focus, display and dismissal. For the iPhone keyboard, focus a guest app’s text field and tap the host toolbar’s keyboard button. Tapping the guest display dismisses the iPhone keyboard. Host key mapping primarily supports English letters, numbers and common symbols.

画面太小或模糊，如何调整？How can I adjust a small or blurry display?+

在 Hardware 中使用 Retina mode 与 Automatically resize guest display，保存并重新打开 App 后生效。开发版默认开启二者，以更高像素密度显示，同时按启动时的屏幕密度调整界面大小。请勿为了缩放界面而随意修改镜像内的显示配置。Use Retina mode and Automatically resize guest display under Hardware, then save and reopen the app. Both default to on in the development build, increasing pixel detail while adjusting interface size to the boot display density. Prefer these controls to manually changing display files in the image.

底部或右侧的一排按钮是什么？What do the host toolbar buttons do?+

齿轮打开模拟器设置；终端按钮在系统画面和串口控制台之间切换；键盘按钮控制宿主键盘。电源、音量加和音量减会向客体系统发送相应硬件按键。串口终端是 Linux 启动与调试控制台，不是已登录的图形终端。The gear opens emulator settings. The terminal button switches between the display and serial console. The keyboard button controls the host keyboard. Power and volume buttons send the corresponding hardware keys to the guest. The serial console shows Linux startup and diagnostic output; it is not an already logged-in graphical terminal.

有些应用较慢或画面异常怎么办？What if an application is slow or displays incorrectly?+

模拟器的图形渲染路径与真机不同，模拟器截图不能代表真机性能。图形适配和应用兼容性仍在完善，部分应用可能无法正常使用。反馈时请写明设备型号、系统与 App 版本、受影响应用及复现步骤，并附上脱敏截图或日志。不要发送密码、私钥或完整磁盘镜像。The simulator uses a different graphics path from a physical device, so these screenshots do not indicate device performance. Graphics and application compatibility remain in development; some apps may not work correctly. Reports should include your device, OS and app versions, the affected application and reproduction steps, with redacted screenshots or logs. Do not send passwords, private keys or complete disk images.
